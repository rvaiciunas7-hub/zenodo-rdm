# Security Policy

This security policy applies to materials published in Zenodo under their respective DOIs.
Zenodo records are immutable archival snapshots; they cannot be modified after publication.

## Reporting a Vulnerability

If you discover a security issue in any file, dataset, document, or code published under a
Zenodo DOI:

1. Do not disclose the issue publicly.
2. Report it privately to the maintainer of the record.
3. Include the Zenodo DOI, version, and a clear description of the issue.

Contact:support@zenodo.org
## Scope

This policy covers:
- Published documents
- Datasets
- Source code archives
- Supplementary materials attached to Zenodo records

It does not cover:
- Zenodo platform infrastructure (report to CERN instead)
- Third‑party dependencies included in archived snapshots

## Zenodo Snapshots

Zenodo entries are permanent archival records.  
Security fixes, if needed, are applied in future releases or repositories referenced by the
record, not retroactively to the archived snapshot.

## Coordinated Disclosure

We support responsible disclosure.  
A fix or mitigation will be prepared before any public announcement.  
Reporters may be acknowledged upon request.
